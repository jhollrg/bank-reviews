# Данные

Датасет **не включён** в этот репозиторий. Он взят из соревнования
[cups.online](https://cups.online) и для скачивания требует (бесплатной)
регистрации - поэтому не публикуется здесь напрямую.

при запуске положить `train.csv` и `test.csv` в `bank-reviews/data`.

## Формат данных

Разделитель — табуляция (`\t`), кодировка UTF-8.

**train.csv**

| idx | Score | Text |
|-----|-------|------|
| 0 | Positive | текст отзыва на русском... |
| 1 | Negative | текст отзыва на русском... |

**test.csv**

| idx | Text |
|-----|------|
| 13999 | текст отзыва на русском... |

- ~14 000 размеченных отзывов для обучения (классы сбалансированы, ~50/50)
- ~6 000 неразмеченных отзывов для теста
- Источник: отзывы клиентов банков с banki.ru
- Средняя длина отзыва: ~1600 символов (свободный текст)
